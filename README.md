# Casa Nómada — E-commerce demo

Proyecto demostrativo de portfolio desarrollado sobre el repositorio `nexo-store-ecommerce`.

## Concepto

Casa Nómada es una tienda online ficticia de decoración, textiles, iluminación y objetos para el hogar. La experiencia fue diseñada para verse y sentirse como un e-commerce editorial real, evitando el lenguaje visual de dashboard o CRM.

## Funcionalidades

- home editorial con identidad de marca propia;
- colecciones destacadas;
- catálogo responsive;
- categorías, búsqueda y ordenamiento;
- ficha de producto en modal;
- variantes/terminaciones;
- stock demostrativo;
- favoritos persistentes;
- carrito lateral;
- cantidades y eliminación de productos;
- cupón demo `NOMADA10`;
- checkout simulado;
- opciones de envío demo;
- confirmación de pedido ficticio;
- newsletter demostrativa;
- persistencia local mediante `localStorage`;
- diseño responsive para escritorio, tablet y celular.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- localStorage

## Importante

Este proyecto fue creado exclusivamente para portfolio. No procesa pagos, no registra pedidos reales y no utiliza datos de clientes. Los productos, precios, stock, promociones y operaciones son ficticios.
